# 🛍️ E-Commerce Website

A modern, responsive, and interactive **E-Commerce Website** built using **HTML, CSS, and JavaScript**. The project provides a clean shopping experience where users can explore products, view product information, filter products, and interact with the shopping interface.

## 🌐 Live Demo

👉 **[Visit the Website](https://haroondarvish.github.io/E-Commerce-Website/)**

## ✨ Features

* 🛍️ Browse available products
* 🔎 Search and explore products
* 🏷️ Product categories
* ⭐ Product ratings
* 🛒 Shopping cart functionality
* 📦 Product information and details
* 🔄 Dynamic product rendering
* ⚡ Interactive user interface
* 📱 Fully responsive design
* 💻 Optimized for desktop, tablet, and mobile devices

## 🛠️ Technologies Used

* **HTML5** — Website structure and semantic content
* **CSS3** — Styling, layout, animations, and responsive design
* **JavaScript** — Dynamic functionality, product management, filtering, and user interactions


## 📱 Responsive Design

The website is designed to provide a consistent experience across different screen sizes:

* 📱 Mobile phones
* 📲 Tablets
* 💻 Laptops
* 🖥️ Desktop computers


## 🎯 Project Purpose

The main purpose of this project is to practice building a realistic **front-end E-Commerce application** using vanilla JavaScript without relying on a JavaScript framework.

This project helped me improve my understanding of **HTML structure, CSS responsive design, JavaScript logic, DOM manipulation, arrays, objects, and interactive web interfaces**.
